# SUNBYEOL

AI 취향 학습 기반 큐레이션 커머스 웹 애플리케이션입니다.

## 주요 기능

- **본인확인 · 연령 및 통관 온보딩**: 휴대폰 교차인증, 주민등록번호 기반 연령(성인/미성년자) 판별 및 주류 카테고리 접근 제어, 개인통관고유부호 형식 검증
- **AI 개인화 추천 & 실시간 피드백 학습**: 선호 카테고리, 가격 vs 판매처 신뢰성 vs 균형 기준, 배송 방식 및 만족/불만족 피드백을 학습하여 추천 순위 반영
- **상품 검색 · 수동 상세 필터**: 카테고리, 가격 범위, 무료배송, 최소 별점, 배송 방식, 정렬 기준(AI 부합도순/가격순/별점순/리뷰순) 통합 검색
- **상품 상세 & 구매자 평가**: 상품별 상세 스펙, 별점 분포, 구매자 리뷰 조회 및 작성
- **장바구니 선택 주문 & 분리 배송 안내**: 선택 상품만 결제, 배송지 또는 배송 방식이 다른 상품 그룹 분리 결제 모달 지원

## 시작하기

### 1. 의존성 설치

```bash
npm install
```

### 2. 환경 변수 설정

`.env.example`을 복사해 `.env` 파일을 만들고 Gemini API 키를 입력합니다.

```bash
cp .env.example .env
```

```env
GEMINI_API_KEY="YOUR_GEMINI_API_KEY"
APP_URL="http://localhost:3000"
```

> `GEMINI_API_KEY`가 없어도 카탈로그 필터 검색, 추천 순위, 장바구니 및 주문 기능은 정상 동작하며, 키 설정 시 외부 판매처 실시간 웹 검색과 AI 개인화 요약이 활성화됩니다.

### 3. 실행 및 빌드

```bash
# 개발 서버 실행 (포트 3000)
npm run dev

# 타입 체크
npm run lint

# 프로덕션 빌드 및 실행
npm run build
npm start
```

### 4. Vercel 배포 안내

이 프로젝트에는 Vercel용 Serverless API 엔트리(`api/index.ts`)와 라우팅 설정(`vercel.json`)이 포함되어 있습니다.

1. GitHub 저장소에 전체 소스를 업로드합니다.
2. Vercel에서 해당 저장소를 Import하면 `vercel.json` 설정에 따라 프론트엔드(`dist`)와 백엔드(`/api/*`)가 함께 배포됩니다.
3. 실시간 외부 웹 검색·AI 요약 기능을 활성화하려면 Vercel 프로젝트의 **Settings > Environment Variables**에 `GEMINI_API_KEY`를 추가하세요. (미설정 시에도 기본 카탈로그·필터·주문 기능은 정상 동작합니다.)
